# ApexPlanet Internship — Task 2

A responsive single-page project demonstrating the four Task 2 activities:
1. Contact form built with HTML and CSS.
2. JavaScript validation for required fields and email format.
3. Responsive layout using Flexbox, CSS Grid, and media queries.
4. Dynamic to-do list with add, complete, delete, and clear-completed actions.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Files
- `index.html` — page structure and form
- `style.css` — styling and responsive breakpoints
- `script.js` — form validation and to-do list behaviour

## Note
The contact form is a front-end demonstration only. It validates the inputs but does not send data to a server. The to-do list keeps data in memory for the current page session and resets when the page is reloaded.
